# Brand assets

Generated by `node scripts/brand.mjs build` from `src/brand/brand.json` (name, subtitle) and the emblem geometry in `scripts/brand.mjs`.

| File | Use |
|---|---|
| `emblem.svg` | Full emblem (arch, keyline, diamond, AE monogram, stitch row) – 56px and larger |
| `mark.svg` | Simplified mark (arch + AE) – below 56px |
| `favicon.svg` | Browser tab icon (linked on every page) |

The header/footer use the inline sprite (`#ae-emblem`, `#ae-mark`) using `--emblem-bg` / `--emblem-ink` / `--emblem-edge` (same values on every background).
Palette: burgundy #691829 badge, ivory #FAF8F5 monogram, muted-rose #C28E98 edge. There is ONE emblem treatment for light, dark, header and footer – the rose edge keeps the badge visible on charcoal.
The wordmark is live text (Cormorant Garamond, tracked caps; last word italic). The brand name is a working name: change it only with `node scripts/brand.mjs set "NEW NAME"`, then redraw the AE monogram for the new initials.
